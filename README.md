# Modular Drone–Rover Docking Research

This repository is a documentation shell for Tenne Tian's hardware-engineering work with the Duke General Robotics Lab, beginning in September 2026. The research concerns an automated drone-docking system that integrates a drone and rover for ice-sheet collection tasks in Greenland.

## Publication permission required

**Do not publish lab code, CAD, algorithms, test data, photos, partner information, or other research materials until the Duke General Robotics Lab and all relevant collaborators explicitly approve their release.** If public release is not permitted, this repository can remain a high-level project page containing only approved descriptions and links.

## Work described in the résumé

- Engineering hardware for an automated drone-docking system integrating a drone and rover.
- Optimizing and testing docking algorithms and drone batch coordination with landing accuracy and energy efficiency as design goals.
- Building a DIY wind tunnel from modified fans for wind-resistance testing.
- Creating drone-framework CAD intended to improve wind resistance.

These statements describe responsibilities and goals. Add quantitative results only after they are measured, verified, and approved for release.
